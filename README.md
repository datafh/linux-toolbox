# linux-toolbox

> 数据渔港 Linux 服务器工具箱 —— 一条命令，把服务器常用运维操作装进口袋。

**版本：V1.0.4.1** ｜ **作者：大鱼（数据渔港）** ｜ **官网：https://datafh.cn**

单文件 Shell 脚本，无需安装任何依赖，覆盖系统管理、网络诊断、磁盘挂载、面板安装、Docker 部署等高频运维场景。由 `linux.sh`（服务器工具箱）与 `docker.sh`（轩辕镜像 Docker 一键安装配置）合并生成。

---

## 🚀 快速开始

在 Linux 服务器上以 **root 或 sudo** 执行：

```bash
bash <(curl -sSL https://raw.githubusercontent.com/datafh/linux-toolbox/main/tools.sh)
```

或先下载再运行（推荐，便于审查脚本内容）：

```bash
curl -sSL https://raw.githubusercontent.com/datafh/linux-toolbox/main/tools.sh -o tools.sh
chmod +x tools.sh
bash tools.sh
```

启动后进入交互式主菜单，输入编号执行对应功能，`q` 逐级返回退出。

## ⚙️ 环境要求

- Linux 服务器（CentOS / Ubuntu / Debian / openEuler 等主流发行版）
- root 或 sudo 权限
- 部分功能需要服务器能访问外网（脚本会自动配置国内镜像加速）

---

## ⚠️ 使用须知

1. **先测试后生产**：脚本会直接修改系统配置（密码、SSH 端口、sysctl、fstab 等），建议先在测试环境验证
2. **操作前备份**：涉及磁盘挂载、格式化、系统更新的操作不可逆，请提前备份重要数据
3. **云服务器注意**：菜单 5（宿主机）的虚拟化操作在云服务器上不可用，请勿尝试
4. **换源提示**：Debian 9 / Ubuntu 16.04 等已停版本会自动提示并使用归档镜像源
